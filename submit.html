Found a corner of the web that belongs down here? Send it down.

  1. Fill in a form below. Pick a link or an image.
  2. Confirm it on GitHub. Pressing send opens the filled-in submission on GitHub in a new tab. Press Create there to send it. You need a free GitHub account.
  3. A curator reviews it. Approved submissions appear on the site automatically, and you get a reply on the submission when it's live.

Submissions are public on GitHub. Don't include anything private.
